# 12-Mexico-Cities
This database was established by Dr. Angelina Espejel for the study egovernment in México. For any questions regarding the dataset or to request permission for its use, please send an email to: angelina.et@gmail.com

The purpose of using this database is purely academic.

Tweets extracted from the accounts of the governments of the twelve most connected cities in Mexico

Espejel-Trujillo, A., & Ortiz-Espinoza, Á. (2024). Uso de X como herramienta de gobierno electrónico: Doce ciudades de México (Cap. 5). En E. L. Ramírez Arellanes, A. C. López García, & D. Soto Hernández (Coords.), Horizontes del Gobierno Electrónico: Una revisión disciplinar y aplicaciones (pp.109-125). Universidad de la Sierra Sur.
